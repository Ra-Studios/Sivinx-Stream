Getting started

From voice to text.

Choose where your words should go, start recording, and finish when you are ready. You can use a keyboard shortcut or the floating microphone.

1. Install and choose your microphone

Download the Windows installer using either Download button on this page. Run the setup wizard, review the terms, and choose an installation folder. Open Sivinx Stream after setup. The installer includes an English speech model for local recognition.

Hover over the widget and choose Settings, or right-click the app's system tray icon and select Settings. In Preferences, choose your microphone, check Windows microphone permission, and use the recording test if needed.

2. Choose where processing happens

Advanced settings separates speech recognition from text formatting. Cloud features require internet access and your own provider credentials; provider charges and limits may apply.

  • Dictation: Use the local English model, or configure a supported cloud transcription provider and model.
  • Live Typing: Configure Deepgram or Google Gemini for supported live recognition. Language and preview behavior depend on the selected model.
  • Formatting: Optionally send the transcript to a text provider for supported writing adjustments. This can send text to the cloud even when speech recognition is local.

To stay fully offline: select local recognition, disable the live provider, and disable cloud formatting. The included local model supports English; selecting a different language does not add that language to this model.

3. Record with your keyboard or mouse

  1. Click inside an editable text field in a document, message, email, or browser.
  2. Hold Ctrl + Alt, or your configured shortcut, and speak.
  3. Release the keys to finish. Keep the destination window selected while processing completes.
  4. Review the inserted text, especially names, numbers, and important wording.

Prefer the mouse? Hover over the widget and click the microphone. Choose the check mark to Finish & Paste, or the cross to Cancel. These controls appear for mouse recording; keyboard recording finishes when you release the shortcut.

4. Make the app fit your workflow

Preferences includes supported shortcut choices, microphone controls, recording sounds, transcript preview, writing modes, and application profiles. Profiles apply writing preferences; they do not start recordings. Vocabulary lets you add preferred spellings and common corrections.

Home shows your latest result. History is off by default; enable it if you want encrypted text history on this Windows account, with a retention period of 1, 7, or 30 days.

5. Recover a result or check a recording

If automatic insertion is blocked, click the destination text field and press Ctrl + V, or copy the latest result from Home. If you see No sound detected, check the selected input, run the microphone test, and check Windows permissions. Review Advanced settings for cloud connection problems.

6. Keep up to date

Version 0.1.1 configures signed updates for future releases. On startup, the app checks its GitHub release feed when internet access is available. A newer release can offer Update Now or Later. Users upgrading from 0.1.0 should install 0.1.1 or a newer release manually once.

A few useful answers

Before you begin.

Can I use Sivinx Stream without internet?+
Yes. Use the included English model for local recognition, disable the live provider, and disable cloud formatting. Cloud transcription and formatting require an internet connection. The startup update check also needs internet access, but offline recognition does not.
Can I record without holding a shortcut?+
Yes. Hover over the widget and click its microphone. Choose Finish & Paste to complete the recording, or Cancel to discard it. With keyboard recording, release the held shortcut to finish.
Which languages are supported?+
The included offline model supports English. Cloud language support varies by provider and model. You can add preferred languages, including Urdu, in Settings; a language selection does not make an unsupported model multilingual.
Do I need an API key, and are there provider charges?+
The included offline model needs no provider API key. Cloud features use your own provider account and credentials. Your provider may charge for usage, limit free access, or restrict particular models. Review its pricing and terms before connecting.
Are my API keys included in the installer?+
No. Saved API keys are stored in Windows Credential Manager on your computer, not copied into the distributed installer. They authenticate requests to the selected provider. Other users enter their own credentials.
Can I change Ctrl + Alt?+
Yes. Choose from the supported shortcut combinations in Preferences. The app offers a restricted set of combinations to reduce accidental typing and conflicts with normal keyboard use.
Why do some models show text only after I finish?+
Transcript preview displays words when your selected provider returns them. Supported live routes can return partial text while you speak; other models return a result after recording ends. Enable Transcript preview in Preferences to see available text.
What if text does not appear in my application?+
Keep an editable field focused while recording and processing. Some applications and Windows permission levels can block insertion. Select the destination and press Ctrl + V, or copy the latest result from Home. Important text should be reviewed before sending.
Does the app run on phones, Mac, or Linux?+
The desktop application currently supports 64-bit Windows 10 and Windows 11. This website can be viewed on a phone, tablet, or computer. No release date is announced here for other desktop platforms.

Privacy Policy +

Effective 19 October 2026 · Applies to the installed Windows application.

The information processed by Sivinx Stream depends on the features and providers you enable. Local recognition, cloud recognition, and cloud formatting handle different information. This policy explains those differences and the controls available to you.

Microphone and recordings

The application captures audio when you start a recording or run a microphone test. Between sessions, microphone capture is paused. Recording audio is held in application memory rather than saved as a routine audio archive.

A failed recording may remain in memory for retry for up to approximately 30 minutes, or until the app exits. The local microphone playback test does not send its test recording to an AI provider.

Local and cloud processing

With local recognition selected, speech is transcribed on your computer. Fully local dictation also requires disabling live providers and cloud formatting.

Cloud audio and live providers receive audio needed for transcription. If cloud formatting is enabled, the selected text provider receives the transcript and relevant instructions, including supported vocabulary hints, even when recognition runs locally. Requests also disclose connection information, such as your IP address, to the receiving service.

Providers operate under their own terms and privacy policies, including rules on retention, training, service locations, and subprocessors. Review the policies for your selected provider and model; Sivinx Stream does not control their practices.

Latest result, history, and clipboard

Your latest completed transcript remains in memory and is available in Home until you clear it or exit the application. Completed dictation is also copied to the Windows clipboard to support pasting.

Text history is off by default. When enabled, it stores up to 100 entries on this device, including the text, time, writing mode, destination application name, and recording duration. Choose a retention period of 1, 7, or 30 days in History. Expired entries are removed during the app’s history cleanup.

Saved history is encrypted using Windows account protection. Delete individual entries, clear history, or turn history off to remove saved entries. These actions do not clear the Windows clipboard, Windows clipboard history or sync, text pasted elsewhere, backups, or copies held by a provider.

Settings and credentials

Preferences, vocabulary, and application profiles are stored on this device. The app identifies the destination application to apply your configured profile and label saved history.

New API keys are saved in Windows Credential Manager and authenticate requests to the corresponding provider. Older installations may retain legacy credentials if migration cannot complete. Protect access to your Windows account and revoke a key with its provider if you believe it has been exposed.

Diagnostics, updates, and support

Routine application diagnostics record operational details such as timings and errors rather than transcript contents. On startup, the app checks its configured GitHub release endpoint for updates. That request exposes normal connection information to the release host; it does not include your recording or transcript. Installation is offered when an update is available.

Information you choose to send to support, including messages, screenshots, or logs, is received through the email or messaging service you use. Share only what is needed and remove secrets before sending. Opening a website, support channel, or donation link uses an external service with its own privacy policy. This policy does not describe those services.

Your controls and security

You can change providers, disable cloud formatting, revoke microphone permission in Windows, disable or delete history, clear the latest result, and manage provider keys. Exiting the app clears its in-memory recordings and latest transcript; closing only Settings does not exit the app.

Windows credential storage and history encryption reduce exposure but cannot guarantee security against a compromised device or account.
